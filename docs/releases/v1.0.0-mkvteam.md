# StudentOS v1.0.0-mkvteam

## Release Purpose

`v1.0.0-mkvteam` is the first named StudentOS milestone for the MKV Team. It packages the current verified project foundation for review, controlled local development, and small-scale pilot validation.

## Included Capabilities

| Area | Included in this release |
| --- | --- |
| Student workspace | Dashboard, tasks, schedule, goals, skills, saved items, profiles, and collaboration-oriented features. |
| Communication | Recipient lookup, messages, unread state, notifications, conversation controls, blocking, and reporting. |
| Account safety | Registration, verification and recovery flows, password changes, role-aware access, revocable sessions, and a seven-day inactivity boundary. |
| Staff operations | Protected administration, moderation reports, audit visibility, account filtering, and a read-only system health check. |
| User experience | Responsive navigation, persistent light/dark preference, mobile-focused drawer behavior, and accessible focus handling. |
| Delivery | Maven WAR packaging, Docker runtime configuration, Render deployment support, and GitHub Container Registry publishing. |

## Verification Summary

The release source passed the Maven test suite and WAR packaging checks. Owner-controlled validation covered public pages, protected-route boundaries, authenticated student and staff workflows, a controlled application restart with persistent-session restoration, a reversible task create/complete/delete workflow, and the non-sensitive database health diagnostic.

## Run the Container Locally

After GitHub Container Registry publishing completes, pull the tagged image:

```bash
docker pull ghcr.io/lankuzumk/student-os:v1.0.0-mkvteam
```

Run it with **your own local or test PostgreSQL database**, not the production database:

```bash
docker run --rm -p 8080:8080 \
  --env-file .env \
  ghcr.io/lankuzumk/student-os:v1.0.0-mkvteam
```

Never share or use a live database connection string, hosting secret, administrator credential, password, reset code, or production account data in a local container.

## Scope Note

StudentOS is presented as a strong university-project and controlled-pilot foundation. Further real-device and independent two-user testing remain appropriate before any broader rollout.
